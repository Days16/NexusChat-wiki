# NexusChat — Wiki

Documentación completa de **NexusChat**, un overlay de chat multi-plataforma
(Twitch, Kick, YouTube, TikTok) para Minecraft (Fabric 1.21.11).

Este repositorio contiene únicamente la documentación (Jekyll +
[just-the-docs](https://github.com/just-the-docs/just-the-docs)), publicada
vía GitHub Pages. El código fuente del mod no vive aquí.

Sitio publicado: **https://days16.github.io/NexusChat-wiki/**
